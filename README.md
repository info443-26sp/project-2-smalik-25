# Project 2 Proposal

## Selected System

TensorFlow is an open-source machine learning framework used for developing and deploying artificial intelligence and deep learning applications. It was  created by Google and is now maintained by the TensorFlow open-source community.

## Context and Background

TensorFlow is a library largely used for several different applications of machine learning, from computer vision to natural language processing. It's most useful for building, training, and deploying machine learning models, and users can also access many different models through this library. Google originally created this library, but since then, the open-source community has managed different changes to the library for the last few years. More information on this library can be found at: https://github.com/tensorflow/tensorflow and https://www.tensorflow.org/api_docs/
